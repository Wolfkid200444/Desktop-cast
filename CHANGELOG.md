# Changelog

## 0.2.0

- Organize source, overlays, assets, integrations, tests and documentation into folders.
- Drag characters partly off-screen or between monitors.
- Render a character across adjacent monitor edges during movement.
- Add Center on screen to recover or move the selected running character.
- Test negative monitor origins and shared drag coordinates.

## 0.1.0

- Native Wayland desktop characters with a library and Steam Workshop browser.
- Compact sidebar layout, live playback controls, rotation, flipping and audio.
- New characters default to 15 FPS.
- Saved positions stay bound to screen geometry when click-through is enabled.
- Character menus dismiss when clicking outside.
- Closing the main window keeps characters running in the system tray.
- Reopening the launcher shows the existing background window.
- Optional KWin helper restores Ctrl + right-click access in click-through mode.
- Versioned AppImage, Debian, RPM and portable archive builds.
